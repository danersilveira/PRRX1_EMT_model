#  Logical model file used to generate the figures for the article entitled "Dynamics of PRRX1 during TGF-β signaling: A computational study of the epithelial-mesenchymal transition"

This repository aims to share the logical model regarding the article entitled "Dynamics of PRRX1 during TGF-β signaling: A computational study of the epithelial-mesenchymal transition".

## Requirements

The model is provided in a .zginml file. It can be read by GINsim software or by the ginsim package in Python language.

> [GINsim software](https://ginsim.github.io/)

> [GINsim-python](https://github.com/GINsim/GINsim-python)
